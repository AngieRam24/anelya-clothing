# ANELYA CLOTHING - Aplicación Web de Moda Circular

Plataforma web para **ANELYA CLOTHING**, emprendimiento dedicado a la recuperación, reparación y transformación artesanal de prendas (*upcycling*) en Medellín.

## Tecnologías Utilizadas
- **Frontend:** HTML, CSS, JavaScript, React, JSX, Vite.
- **Backend:** Node.js, Express, MongoDB Atlas, Mongoose.
- **Despliegue:** Git, GitHub, GitHub Pages y Render.

## Instrucciones para ejecutar localmente
1. Clonar el repositorio: `git clone https://github.com`
2. **Backend:** Entrar a `/backend`, crear el archivo `.env` con `PORT`, `MONGO_URI`, `ADMIN_EMAIL`, `ADMIN_PASSWORD` y `ADMIN_TOKEN`, ejecutar `npm install` y luego `node server.js`.
3. **Frontend:** Entrar a `/frontend`, ejecutar `npm install` y luego `npm run dev`.
